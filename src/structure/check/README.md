**Support** — compose deterministic snapshot observations and the debt comparison.

The public check facade delegates here. Parse tracked code once, measure
production src, and retain separate static coverage, load and historical data.
Source text is never executed. Reports are advisory; incomplete input is not
compliance. File-move debt uses an exact text hash, while runtime units retain
their documented canonical body-token identities.

A comparison retains one syntax tree per exact path and text shared by head
and base. The reuse is local to that comparison and includes test readers.
File metadata, measurements, public roles, graph, references and reader results
are recomputed for each tree. Changed text or a different path is parsed anew.

The pre-existing module-level WeakMaps in `bindings/scopes.mjs` and
`bindings/uses.mjs` (SourceFile keys) and `graph/value-use.mjs` (declaration-node
keys) may get cross-tree hits for shared ASTs safely because their cached
results depend only on one file's syntax.
