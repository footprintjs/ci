**Support** — compare old and new structural debt without a baseline file.

Matching is injective: one old unit cannot excuse multiple head units. Reports
retain new, existing, improved and removed debt, plus total excess by rule.

`profiles` keeps all metrics for one unit together. `match` prefers the same
location, then a unique body hash, then a unique named identity. `observations`
compares every rule against that single owner; `totals` independently reports
non-growth per rule. `coverage` exposes unresolved identity and extraction work.
No module evaluates candidate code or selects a candidate-provided limit.

`compareFindings(head, base)` returns the four debt arrays, totals with
`baseExcess`/`headExcess`/`delta`/`regressed`, and coverage. New or ambiguous units
remain conservative regressions. Ambiguity is not guessed away. Named identities
survive moves and shrinkage; file identity stays path-based unless an exact
whole-file body hash is available. All metrics of a matched unit share one old
unit, so different old functions cannot subsidize its different rules.

`moves/` recognizes intact top-level declarations using full canonical declaration
tokens and declaration kinds (only export/default wrappers are ignored). Every
head occurrence must fit the base inventory, so copying a unit does not reuse
one old unit. New-leaf credit is `moved` only when raw total excess for that rule
strictly falls. Changed headers and nested partial extractions do not qualify.
Evidence lists candidate base source locations, rather than guessing one owner.

A file that becomes a facade measures its base under the same head shape.
Direct-import growth is separately allowed only when the same file code lines
fall; raw count/delta and the explicit wiring allowance stay visible. This
exception does not turn total growth into whole-leaf move credit.

**Unimplemented:** partial extraction needs measured token-overlap calibration.
An unmatched callable/class with old same-kind debt gets an explicit incomplete
observation; no threshold or credit is fabricated. Removed debt is recorded even
when another unit regresses. Per-unit growth cannot be hidden by shrinking a
different unit.
