**Support** — recognize intact top-level relocation and split wiring allowances.

Each unit has a syntax kind, name and canonical body hash. Imports/reexports are
wiring; declaration export wrappers do not change a body. A new leaf qualifies
only when every top-level unit existed at base and all head occurrences fit the
base inventory injectively. Nested partial extractions do not qualify.
Actual debt credit additionally requires the relevant rule's total excess to
fall. This is structural debt accounting, not proof of behavior or public API.

Same-file direct-import excess may grow only when that file's code lines fall.
The raw count/delta and the explicit allowed growth remain in the report.
