# Native inspection composition and reobservation

The production Foottrace inspection factory extends a trusted CODE predecessor
with the existing discovery/bootstrap and shared inspection recipe. A single
owning native executor records source prefix, discovery, inspection result and
the caller's continuation. The stand-alone read-only source facade executes this same recipe.
No DATA field can supply a predecessor, executor, reader, profile or saved input.

The factory's backend contains runtime INPUT observations only. The declared
result-stage ID and backend availability do not prove the owning executor has
committed that stage. A later effect controller must inspect its actual completed
native prefix and independently require all eligibility, reviews/refusals,
grants, reservations, history, current producer, checks and writer predicates.
The full owning nonforce controller and physical workflow caller are unfinished.

The production reobserver reuses the SAME native readers and binding guards:
ordinary source reconstruction, published L, source ancestry, pending reviews
and permissions, complete workflow collection, independently bound retained
witnesses, source versions, candidate conflicts, current running producer and
current preparation archive. It reclassifies retained native attempts. Native
bootstrap rechecks M/P/L, the current reconstructed source and the complete
workflow collection before and after this sequence. No historical target helper
or saved record executes, and no separate executor or authority mechanism exists.

Successful reobservation means the newly read INPUT bindings equal the original
ones. Ineligible retained attempts remain ineligible. This does not establish
global/provider continuity, erased history, original creator, permissions for
the current writer, a native grant or release readiness. It does not relax the
strict in-progress/current-attempt and successful-prepare requirements.

A failed reobservation permanently hides this invocation's backend. Later
unchanged observations cannot revive it. Concurrent reobservations invalidate
rather than allow one pending sibling to restore data. Reusing the same factory
with another executor also permanently invalidates its pending prefix, with a
technical native failure. The public facade returns no backend for an incomplete
or truncated whole record, even if an earlier input stage completed.

No mutation port is invoked here. Exact same-tree C1 metadata reconciliation is
still a separate path from pending eight-hop REF-REFRESH. Non-idempotent
uncertainty still requires native GET verification and HOLD across invocations.
No result or diagnostic record grants retry authority.
