# FootprintJS CI repository

This is a placeholder repository. Its current tree contains an MIT [license](LICENSE); it does not contain CI
workflows, reusable actions, a package or runnable examples. There is no installation or execution command here.

For working FootprintJS code and its repository-specific checks, start with:

- [FootPrint](https://github.com/footprintjs/footPrint): the TypeScript workflow engine.
- [Foottrace](https://github.com/footprintjs/foottrace): execution-record writing, replay and evidence readers.
- [Interactive playground](https://footprintjs.github.io/footprint-playground/): an introduction to workflow tracing.

Repository-specific CI lives with the corresponding library; follow its contribution and verification instructions.
